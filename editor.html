Portfolio Content Editor

Edit your website content without rewriting HTML or CSS. Download the updated JSON and replace content.json in your GitHub repository.

How it works: Changes are private in your browser until you download the file and upload it to GitHub. This editor does not directly publish changes. You can also edit content.json manually in GitHub.

Publishing your updates

1. Click “Download updated content.json”.
2. On GitHub, open your Portfolio repository.
3. Select content.json, use the edit/upload option, and replace it with the downloaded file.
4. Commit your changes. GitHub Pages will update your website after deployment.

To change section order, card layout, fonts, or colors, edit index.html and styles.css. To add project images, upload the images to assets/ and enter their paths in the project editor.
